# Harnessgram bundled fonts

Bundled for the "Message font" choice (message bubbles and the input field, build 11) and the "App font" choice
(the whole app, build 22) in Settings > Harnessgram: Assistant, Heebo, Rubik, Frank Ruhl Libre and Secular One,
all under the SIL Open Font License 1.1 (`OFL-<Family>.txt` next to each font).

Sources, the pinned google/fonts commit, upstream paths, weights and SHA-256 sums: `FONTS_PROVENANCE.md`.
